# Utilizing Machine Learning Techniques for Timely Diagnosis of Parkinson's Disease

This repository contains research focused on the use of **Machine Learning (ML)** techniques for the timely diagnosis of **Parkinson's Disease (PD)**, a progressive neurological disorder that affects movement. Early diagnosis is crucial for improving treatment outcomes, and this work explores how **ML** can aid in detecting the early signs of Parkinson's Disease using various data sources like speech, handwriting, gait, and neuroimaging.

## Project Overview

Parkinson's Disease (PD) is a neurological disorder caused by the degeneration of dopaminergic neurons, leading to motor and non-motor symptoms. Diagnosing PD in its early stages can be difficult, especially in the elderly population where symptoms may overlap with other health conditions. This project uses **machine learning (ML)** to address this challenge by analyzing speech, handwriting, and gait data for early detection of PD.

The project reviews several ML techniques and datasets to propose effective diagnostic models. It provides an in-depth look at using speech frequency analysis, gait patterns, handwriting features, and neuroimaging data for accurate diagnosis and classification of Parkinson's Disease.

## Tech Stack

- **Machine Learning Algorithms**:
  - Support Vector Machines (SVM)
  - Artificial Neural Networks (ANN)
  - Logistic Regression
  - Decision Trees
  - Random Forest
  - K-Nearest Neighbors (KNN)
  
- **Data Sources**:
  - **Speech**: Voice frequency analysis to track PD progression.
  - **Handwriting**: Analyzing handwriting patterns to detect PD.
  - **Gait**: Using gait features for diagnosis.
  - **Neuroimaging**: MRI and OCT for detecting brain structure changes.

- **Tools**:
  - **Python**: Used for implementing the ML algorithms.
  - **MATLAB**: For data analysis and model building.

## Research Methodology

### Data Acquisition
- Data was collected from various scientific databases including **Web of Science**, **IEEE**, **Scopus**, and **ScienceDirect**.
- A review of over 103 articles (1996–2022) helped gather insights into the latest research on using ML for Parkinson's diagnosis.

### ML Models
- Various machine learning models were explored to predict Parkinson's Disease:
  - **Speech Analysis**: Analyzing voice characteristics using ML models.
  - **Handwriting Patterns**: Examining handwriting dynamics for detecting PD.
  - **Gait Data**: Identifying gait abnormalities using ML algorithms.
  - **Neuroimaging**: Using MRI and OCT images to detect PD-related brain changes.
